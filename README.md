# 📚 어셈블리 프로그래밍 (Assembly)

## 🎯 교육 목적

컴퓨터 하드웨어와 어셈블리 언어의 연동 구조를 이해하고 시스템 수준의 프로그래밍 능력을 배양한다.

* ⚙️ **하드웨어 구조 이해**: CPU 명령어 집합, 레지스터, 메모리 접근 및 스택 동작 파악
* 🛠️ **시스템 프로그래밍**: 로우 레벨 하드웨어 제어 및 실전 프로그래밍 능력 강화
* 🔄 **고급 언어 연동**: C 언어와 어셈블리 간 관계 이해, 컴파일러 및 OS 내부 동작 원리 습득

> 💡 **시스템 로우레벨 입문**: 컴퓨터 내부 동작을 깊이 있게 이해하고, C 언어와 운영체제의 작동 원리를 밑바닥부터 파악한다.
